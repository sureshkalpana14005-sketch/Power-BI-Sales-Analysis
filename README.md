# Sales Performance Analysis Dashboard

## Project Overview

This project uses Microsoft Power BI to analyze sales performance and present business insights through interactive dashboards.

## Objectives

* Analyze total revenue, profit, and order performance.
* Understand customer purchasing behavior.
* Evaluate product and category performance.
* Explore geographical sales distribution.
* Monitor return rates and business KPIs.

## Dashboards

* **Executive Dashboard:** Overview of key business performance metrics.
* **Customer Dashboard:** Analysis of customer segments and purchasing patterns.
* **Product Dashboard:** Product-level performance analysis.
* **Map Dashboard:** Geographical visualization of sales performance.

## Tools and Technologies

* Microsoft Power BI
* DAX
* Power Query
* Data Modeling
* Data Visualization

## Project Files

* `Sales_Analysis_Dashboard.pbix` — Power BI report file.
* `Screenshots/` — Dashboard screenshots.
* `README.md` — Project documentation.

## How to View the Project

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report pages and interactive visuals.
